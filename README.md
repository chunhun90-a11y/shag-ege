# Шаг — подготовка к ЕГЭ

Вводное веб-приложение: информатика и русский язык, 12 занятий и 60 авторских упражнений по темам материалов ФИПИ. Не официальный продукт ФИПИ или Duolingo, не полный курс и не демоверсия.

## Публикация GitHub Pages

В репозитории откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку main, папку / (root), затем Save. После успешной публикации ожидаемый адрес: https://chunhun90-a11y.github.io/shag-ege/ . Само наличие файлов в репозитории не подтверждает включение Pages.

## Запуск и данные

Для локального запуска скачайте файлы index.html и course.js в одну папку и откройте index.html в браузере. Нет серверной части. Прогресс хранится в localStorage; резервная копия — через экспорт и импорт JSON. Поддержка хранения локальных файлов зависит от браузера. Серия и повторения используют локальную дату устройства. Правильные решения: 15 XP за первый успех, 5 XP за повторный успех в другой день; повтор того же задания в течение дня не даёт опыт.

Режимы: карта уроков, повторение ошибок и заданий по сроку, мини-проверка из того же банка без таймера, статистика и резервная копия. Не реализованы запуск Python, сочинение, экспертная оценка, полный экзамен, аккаунты и синхронизация.

## Источники

Информатика: Навигатор ФИПИ 2026, теоретические основы. Русский язык: Навигатор ФИПИ 2025, орфография; использованы словарные примеры. Все ссылки доступны в разделе ФИПИ приложения. Банк официальных заданий не импортирован. При проверке страницы демоверсий 14.10.2026 документы ЕГЭ-2027 обозначены как проекты; статус может измениться.
